# Security Policy

## Supported versions

Security updates are provided for the latest released version of `ddev-workspaces`.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/alessandrotesoro/ddev-workspaces/security/advisories/new).
Do not open a public issue for a security vulnerability.

Include enough information to reproduce and assess the issue:

- The affected version and operating system.
- A description of the impact and required preconditions.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation, if known.

Reports will be acknowledged through the private advisory. Please allow time to investigate and coordinate a fix before public disclosure.
