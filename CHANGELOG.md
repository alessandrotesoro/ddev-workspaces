# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-09-01

### Added

- `doctor`, `create`, `list`, and `remove` commands for conservative local Git worktree management.
- Strict repository configuration for tracked templates, private local files, preparation commands, readiness checks, and optional DDEV integration.
- Source-only workspaces and read-only creation and removal preflights.
- Fail-closed ownership records, Git integrity checks, exact DDEV identity validation, and confirmation-protected cleanup.
- Release automation for Apple Silicon macOS and x86-64 Linux, including shell, Homebrew, and npm installers and GitHub artifact attestations.
